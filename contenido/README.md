# Contenido

Kit de edición y guías para los videos de Raúl Albright (@raulalbright): vlogs de viaje y negocios, reels de IA y la producción audiovisual de ALIAS.

- [CLAUDE.md](CLAUDE.md): guía completa (estilo, flujo de edición y reglas). Es lo que lee Claude Code.
- [kit/](kit): scripts de edición (ffmpeg, faster-whisper, ElevenLabs) y efectos de sonido.
- [plantillas/proyecto](plantillas/proyecto): ejemplos de `edl.json`, `textos.json` y `mezcla.json`.
- [estrategia.md](estrategia.md): qué publicar, cuándo y qué medir.
- [calendario.md](calendario.md): plan del 15 al 28 de noviembre y lista de grabación.
- [publicacion/](publicacion): descripción, créditos y checklist de cada post.
- [historico/aprendizajes.md](historico/aprendizajes.md): proyectos hechos y lecciones.

El material de video vive en `~/Movies/Vlogs` en la Mac. Este repo es público, así que aquí no se suben videos, claves ni datos privados.

Orden: `ingesta → limpiar_voz → transcribir → (edl.json) → corte → transcribir --corte → (textos.json) → subs → (mezcla.json) → mezcla`.
